# NexAPK

Professional mobile-first APK discovery platform.

## Stack
- Next.js
- TypeScript
- React
- Supabase (to be connected)
- Object storage/CDN (to be connected)

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000
